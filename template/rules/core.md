# Core rules: voice and quality bar

These apply to everything: copy, design, code, and how you talk to the owner.

## Voice

- **Sound like a human wrote it.** Read every sentence back and ask: would a person actually say this? If it sounds like placeholder text, rewrite it.
- **No AI slop.** Never write "delve", "furthermore", "in today's fast-paced world", "look no further", "whether you're X or Y". Never open with "Welcome to...". Cut every sentence that exists to fill space.
- **Real opinions, real specifics.** "Baked at 4am, sold out by 10 most Saturdays" beats "the finest baked goods in town." Concrete details are the brand.
- **No em dashes.** Use commas, colons, or parentheses. (Yes, this is a house rule. It keeps the copy from reading as AI-generated.)
- **Short words, short sentences.** The owner should be able to read any page aloud without stumbling.

## Quality bar

- **Nothing stock-looking.** No generic hero gradients, no lorem ipsum, no "John Smith, satisfied customer" testimonials. If an image looks like it came from a stock pack, replace it or remove it.
- **Every page earns its place.** If a page doesn't answer a question a customer actually has, cut it.
- **Mobile first, always.** Most visitors arrive on a phone. Check every change at 390px wide before anything else.
- **Fast is a feature.** No framework, no heavy libraries, images optimized. If a change adds more than ~50KB to first load, justify it out loud before shipping.
- **Accessible by default.** Semantic HTML, real buttons and links, alt text on every image, visible focus states, color contrast that passes, works without JavaScript for all content.

## When in doubt

Ask the owner. A two-minute question beats a confident wrong guess, especially for anything customer-facing. But ask *one* sharp question, not a survey.
